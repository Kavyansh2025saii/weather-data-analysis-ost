# Weather Data Analysis Application
A containerized weather data analysis and rainfall prediction project using Python, Git, GitHub, Docker and Docker Compose.

# Problem Statement
Weather conditions such as temperature, humidity, air quality, wind speed, and cloud cover can influence rainfall. However, analyzing these weather parameters manually can be difficult when working with large datasets. 
This project aims to develop a Weather Data Analysis Application that analyzes historical weather data, identifies patterns between different weather parameters and rainfall, and uses a machine learning model to predict rainfall based on selected weather conditions.

# Scope
The project will cover:
1. Loading and analyzing historical weather data.
2. Checking the structure and quality of the dataset.
3. Analyzing important weather parameters.
4. Creating visualizations to understand weather patterns.
5. Training a Linear Regression model for rainfall prediction.
6. Evaluating the model using MAE, RMSE, and R².
7. Developing a simple application for weather analysis and rainfall prediction.
8. Containerizing the application using Docker.
9. Using Docker Compose to manage the application environment.
    
# Objectives
To analyze historical weather data.
To understand relationships between weather parameters and rainfall.
To visualize important weather patterns.
To build a machine learning model for rainfall prediction.
To evaluate the performance of the model.
To develop a simple and reproducible weather analysis application.
